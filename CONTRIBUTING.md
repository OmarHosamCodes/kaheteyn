# Contributing to Kaheteyn

We welcome contributions to Kaheteyn! Please read these guidelines to help us maintain a productive and respectful development environment.

## How to Contribute

1.  **Fork the repository** and create your branch from `dev`.
2.  **Make your changes**, following the existing code style and structure.
3.  **Run tests and linters** to ensure everything is working correctly:
    ```bash
    bun run check
    bun run check-types
    ```
4.  **Submit a pull request** describing your changes and why they are needed.

## Style Guide

- Follow the existing project structure (`apps/`, `packages/`).
- Use the provided scripts to manage tasks.
- Keep components small and reusable.

Thank you for helping improve Kaheteyn!
